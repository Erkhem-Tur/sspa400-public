ALC BOOK 18 · LESSON 3 · EMPLOYMENT
SCORM 1.2 / Standalone HTML package

LMS upload
1. Upload the ZIP file as a SCORM 1.2 course package.
2. Set completion to the SCORM-reported completion status.
3. The lesson reports a score equal to the percentage of pages viewed.
4. Completion is reported after all 28 pages have been viewed.

Standalone use
Open index.html in a current browser. Progress is saved in that browser.

Navigation
- Use Previous/Next, the contents panel, or the page selector.
- Keyboard: Left/Right, Home/End, and +/- for zoom.
- The lesson is responsive and works on desktop, tablet, and phone.

Interactive workbook
- Every lesson page includes a matching answer workspace.
- Exercise groups and item numbers follow the labels on the visible book page.
- Short answers use fill-in fields; extended responses use writing areas.
- Page 87 includes Past Robots / Both / Today's Robots response areas.
- Page 88 includes a large summary-writing area.
- Answers save automatically in the learner's current browser.
- The SCORM resume record stores page-level practice counts; full written
  responses stay in the learner's browser to remain within SCORM 1.2 limits.

Translanguaging support
- EN ↔ MN Support is available on every page and is on by default.
- The optional bridge does not replace or alter the English student-book text.
- Learners first process the idea briefly in Mongolian, select English key
  language, and then produce the final spoken or written response in English.
- Each page has a task-specific Mongolian strategy, Key English list, and
  reusable English sentence frame.
- Wrong-answer correction guidance is bilingual while support is on.
- Learners or teachers can switch the support off for English-only practice.

Answer checking
- Every response has its own Check button for immediate, on-the-spot feedback.
- Incorrect answers receive a correction guide instead of revealing the answer immediately.
- After two unsuccessful item attempts, Show answer becomes available for that item only.
- Press Enter in a short-answer field to check that item immediately.
- Check answers at the bottom still checks the whole page when needed.
- Correct fields are green; fields needing another attempt are red.
- After two page-level attempts, Show answers becomes available for the whole page.
- Open-ended speaking, personal, diagram, Venn-map, and summary responses are
  labeled Teacher review and are not assigned a false right/wrong result.
- 149 objective response fields have automatic checking.
- The LMS raw score reports correct auto-graded answers as a percentage of all
  available objective items; lesson completion still depends on viewing all pages.

Teacher note
The source PDF did not contain an official answer key. Automatic keys were
carefully derived from the visible lesson content. Before using scores for a
high-stakes assessment, compare them with the institution's official teacher
edition and revise any local answer-key conventions if needed.

Content preservation
All 28 source pages are displayed as enhanced page images. No source text was
retyped, rewritten, omitted, or rearranged.
